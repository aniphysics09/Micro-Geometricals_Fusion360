# Micro-Geometricals_Fusion360
This repository contains Python scripts for creating 3D structures in Fusion360

The codes can be imported into Fusion, and it creates a 3D structure when the code is run through Fusion.

UTILITIES > ADD-INS > Scripts and Add-Ins > Script or add-in from device

Each Python script contains a code for creating a well-shaped container with a rectangular base with a thin wall.
The inner area of the container contains a few hundreds of tiny structures - with dimensions varying randomly between 1 mm to 5 mm.
There are regular geometrical structures, like cuboids, hemispheres, cylinders, prisms, etc.
Each script is for creating one type of structure in the middle area.

Due to large number of the tiny structures, it may take long time to run the script in Fusion and create the design. It may take as long as 30 minutes.
The default number of tiny structures is set to 500 in the scripts. It can be changed as required.

The CAD files are to be used for 3D printing of the blocks. Those blocks are to be used for filling with scattering liquid, and imaging the tiny structures imerged in the scattering medium. Those images are to be used for data analysis experiments for imaging through scattering media.
